Le mode d’emploi

Mon site dans KompoZer

Les repères pour ouvrir et modifier les pages du site.

  1. Décompresse toute l’archive en gardant ses dossiers.
  2. Dans KompoZer, ouvre index.html. Les autres pages sont de vrais fichiers HTML que tu peux modifier séparément.
  3. Change les textes en mode normal, les liens et images avec les outils de KompoZer. Garde leurs chemins relatifs.
  4. Pour utiliser la lecture, les imports et les sauvegardes, ouvre le site dans un navigateur moderne. Le rendu de l’éditeur peut différer du navigateur.
  5. Cherche un livre par son titre ou son auteur, puis ouvre sa présentation. L’ajout et la modification du catalogue sont réservés à l’atelier administrateur en ligne.
  6. Exporte régulièrement tes données dans Mon espace → Mes sauvegardes.

Pour l’ouvrir toujours à la même adresse

Avec Python installé, lance python -m http.server 8000 dans le dossier du site puis ouvre http://localhost:8000. Cela stabilise l’adresse utilisée pour les sauvegardes.

Ce que cette version fait

Sélectionne le texte d’une page PDF pour le surligner. Les passages, les couleurs, les annotations et les fiches sont enregistrés automatiquement. Retrouve-les dans Mon espace ; filtre les passages par couleur ou par livre. Dans les journaux, recherche le titre du livre avant d’écrire.

Ce qui demande une partie serveur

Comptes, partage entre appareils, critiques publiques, réponses, modération et administration protégée. KompoZer édite les pages ; ces services ne sont pas fournis par ces fichiers locaux.

Sources et crédits

Les six couvertures et la photographie de bibliothèque viennent des pièces jointes du projet. Les notices externes des livres sont liées depuis leurs fiches. Les illustrations de genres sont détaillées dans le fichier des sources visuelles.
